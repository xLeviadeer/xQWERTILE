# xQWERTILE
Welcome to the xQWERTILE home-page. xQWERTILE is a software ecosystem of connected tools for defining, interpreting, typing, translating and implementing ⸉Tile⸉ (programming language) and ⸉TileLang⸉ (English language extension) and any other related content. 

## Tile & TileLang 
Tile is a (to be implemented) object oriented general purpose programming language which is formatted like a mix of Python and C#.

TileLang is an ⸉English language extension⸉ | TileLang is a set of grammar rules that define additional allowed rules on top of English. TileLang has a focus on usage of an extended character set to express existing concepts in less characters or express specific concepts that do not have an existing expression within English.
